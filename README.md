# zehut-dashboard
Tomer's Zehut projects dashboard until election day (27.10.2026).
Design: OpenDesign `nike` system, dark-adapted (option 3 from ~/open-design/mockups/zehut-dashboard).
Data: read-only, live from the election board (https://torahworldwide.github.io/election-board/data.json).
To change a project, edit ~/zehut-board/data.json and run ./update.sh — both pages update.
